# Ninka FoodLab v0.2.0 内测版

这是供内部测试的跨平台预发布版本。请勿把它作为唯一的正式研发数据存储，也不要把营养、成本或法规试算直接当作检测报告或正式合规结论。

升级或覆盖安装前，请先在应用的数据管理页创建一份 `.foodrd-backup` 备份；详细注意事项见[升级说明](../upgrade-guide.md)。

## 安装包

- macOS 13.5+ Apple Silicon：`food-rd-studio-0.2.0-macos-arm64.dmg`
- macOS 13.5+ Intel：`food-rd-studio-0.2.0-macos-x64.dmg`
- Windows 10/11 x64：`food-rd-studio-0.2.0-windows-x64-setup.exe`

所有文件均附带在 `SHA256SUMS.txt` 中。macOS 安装包未使用 Apple Developer ID 签名且未公证；Windows 安装包未使用 Authenticode 签名，因此系统可能显示开发者或 SmartScreen 提示。请先核对下载来源和 SHA-256，再决定是否打开。

## 本版重点

- 将 Agent 工作区收敛为会话式界面，并统一品牌为 Ninka Agent。
- 支持会话归档与恢复、稳定输入区、附件名称省略和会话状态提示。
- 支持在同一会话中切换 API 模型，并保留受控的配方上下文、工具审批和成果记录。
- 内置固定版本的 Agent 运行组件，用户无需另外安装 Node 或 pnpm。
- 改进深浅色主题、图标和表单对比度，以及 Provider 配置界面。
- 补齐 macOS Apple Silicon、macOS Intel 和 Windows x64 的独立构建与运行时完整性校验。

## 验证状态

- macOS Apple Silicon：已完成本机 DMG 挂载、应用架构和内置运行时校验。
- macOS Intel：已完成 Intel 架构 DMG 和内置运行时校验，仍待 Intel Mac 实机界面试装。
- Windows x64：由 Windows GitHub Actions 构建，并在 runner 中静默安装后校验内置运行时；仍待真实 Windows 10/11 设备完成界面、SmartScreen、升级和卸载验收。

详细安装与反馈方法见 Release 附带的 `README.md`。
