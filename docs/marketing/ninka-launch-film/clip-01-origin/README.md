## Clip 01: 第一道记录被唤醒

### References

- Characters: none。
- Location and props: 首帧为暗森林绿泥板微距；尾帧为同一材质、同一光线下形成的九模块矿物光点。
- Style: 高端软件发布片、克制的电影级材质研究；Forest 为主色，Grain、Cream 和极少量 Tomato 为光点颜色。

### Start state

9:16 竖屏极近景。摄影机贴近一块几乎融入黑暗的干燥泥板与矿物表面，画面只有一道浅刻痕。侧面低位光源勾出细微颗粒；刻痕中只有极小范围的暖金微光。主体略高于画面中心，底部和右侧保持暗色留白。

Opening anchors: no characters; vertical frame; fixed camera axis; dry clay surface; low side light; one shallow groove; sparse grain dust.

### Camera and action

全程一个连续镜头，不切镜。开场摄影机近乎静止，让材质先被看清。随后摄影机沿刻痕做极慢、稳定的短距离滑移，浅景深焦点跟随一粒暖金光从刻痕向画面中心移动。光经过的位置只有少量矿物尘缓慢抬起，周围细小颗粒克制地向中心聚合。摄影机保持同一轴线，轻柔拉远并逐渐抬焦，泥板表面从极端微距变为可辨识的局部。刻痕里的光缓慢转移到九个嵌入泥板的浅层节点，节点按照尾帧的准确位置和轮廓逐一亮起：上、下、左、右四个向外的种子形节点，内部五个圆形节点。最终运动完全停止并稳定停在尾帧构图，为下一段 Logo 成形留出干净交接。

### Dialogue and sound

无人物、无对白、无旁白、无字幕。首版按静音画面生成；泥土摩擦、低频脉冲、颗粒聚合和节点点亮音效全部在剪映后期添加。若生成平台自动产生音乐，剪辑时静音弃用。

### End state

摄影机已经轻柔拉远，同一块暗森林绿泥板占据画面。九个发光矿物节点准确形成 Ninka 标志的几何轮廓，位于画面中心略偏上，约占画面高度的 22%。光线克制、尘埃基本落定，没有出现正式平面 Logo、文字或其他符号。

### Constraints

保持首尾帧为同一表面、同一摄影机轴线、同一低位侧光和同一深森林绿色调；最终必须恰好九个节点，不能增加、缺少、融合或错位；不要生成可读楔形文字、字母、数字、字幕、Logo 文字或水印；不要出现人物、建筑、神庙、火焰、啤酒杯、蓝色霓虹、科幻 HUD、魔法爆炸或额外图腾；不要提前生成完整的扁平彩色 Logo；镜头运动必须缓慢、稳定、连续，无闪烁、跳切、抖动和材质变形。

## 失败镜头修复语句

### 节点数量或位置错误

```text
保持泥板材质、镜头位置、光线、颜色和运动不变。只修正最终节点：必须恰好九个，并严格匹配尾帧的四个外向种子形节点和五个内部圆形节点。删除所有额外光点，不能融合或错位。保持最终画面停在尾帧构图。
```

### 画面变成泛科技蓝光

```text
保持原有镜头和九节点动作不变。只修正视觉风格：去除全部蓝色霓虹、HUD、电子线路和科幻界面；恢复暗森林绿泥板、暖金与乳白矿物光点、低位侧光和克制的历史材质感。
```

### 镜头过快或过度炫技

```text
保持开场和尾帧不变。只修正运动：取消快速推拉、旋转、甩镜、爆炸和跳切；改为同一轴线上的极慢滑移、轻柔拉远和稳定抬焦，所有尘埃与点亮动作都缓慢连续。
```

## 后期声音建议

- 开场：非常轻的干燥颗粒摩擦声。
- 光沿刻痕移动：低音量、无旋律的细金属泛音。
- 九节点依次亮起：九个很轻的颗粒点击声，不要做成键盘声。
- 尾帧稳定：一个短促、低频、无拖尾的品牌确认音。
- 音乐在本段保持极简，到第二段 Logo 正式形成时再进入主节拍。
