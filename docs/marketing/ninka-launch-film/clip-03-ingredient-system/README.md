## Clip 03: 原料成为系统

### References

- Characters: none。
- Location and props: 首帧为第二段完整 Ninka 九模块图形；尾帧为五个透明原料样本舱、中央 Grain 核心、金色轨道和奶油白节点。
- Style: 深森林绿材料实验场、真实食品材质、薄玻璃、克制的高端软件发布片光线。

### Start state

9:16 竖屏。完整 Ninka 九模块图形位于中央略偏上，中央黄色圆形保持暖金光，背景为连续的深森林绿色空间与少量矿物微尘。摄影机与第二段尾帧保持同一中心轴线。

Opening anchors: vertical frame; centered camera axis; complete nine-module mark; warm central core; dark Forest background.

### Camera and action

- `0.0–1.0 秒`：第二段尾帧保持稳定。中央黄色圆形出现一次很轻的呼吸亮度，其他八个模块不变形。
- `1.0–2.2 秒`：摄影机沿中心轴缓慢向中央黄色核心推进。外围模块沿短弧轻柔离开原位，化为克制的食材颗粒与细小光点，不能爆炸或高速旋转。
- `2.2–4.2 秒`：穿过暖金光的同时，空间从品牌图形过渡为现代深森林绿材料实验场。颗粒分别聚合进五个透明圆角样本舱，形成白砂糖晶体、脱脂乳粉、琥珀色浓缩液、浅金色油脂和可可色颗粒；中央黄色核心始终保留。
- `4.2–5.3 秒`：五个样本舱移动到尾帧的准确位置。细金色轨道线从中央向外依次描出，奶油白节点逐个亮起，五个原料样本被连接成一个有秩序的系统。
- `5.3–6.0 秒`：所有运动缓慢停止，玻璃反光、原料位置、轨道和背景完全落到尾帧构图。最后不继续推镜，为下一段配方组合保留稳定交接。

### Dialogue and sound

无人物、无对白、无旁白、无字幕。首版按静音画面生成；全部音乐和音效在剪映后期添加。

### End state

摄影机停止在尾帧构图。五个透明样本舱准确分布在中央 Grain 核心周围，分别包含白砂糖晶体、脱脂乳粉、琥珀色浓缩液、浅金色油脂和可可色颗粒；细金轨道和奶油白节点完整连接，背景与留白稳定，方便第四段继承。

Closing anchors: five fixed specimen capsules; central Grain core; complete gold orbits; stable vertical framing; quiet lower safe area.
