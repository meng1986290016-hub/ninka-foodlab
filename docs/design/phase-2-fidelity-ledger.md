## 可见文字差异

- 概念图的“本地数据库 / 已同步”在浏览器验证环境中替换为真实状态“浏览器演示数据 / 离线可用”，避免制造已接通 SQLite 的假象。
- 实现增加一句页面说明“维护配方计算所需的基础原料、价格和来源信息”，用于解释当前阶段范围。
- “恢复草稿”只在确实检测到兼容草稿时出现，不作为常驻装饰操作。
- 原生 Windows/macOS 窗口控制由未来 Tauri 窗口装饰提供，未在网页内容中仿造。

这些均为有意且与当前运行状态一致的差异；没有遗留可修复的布局、颜色、字体或交互偏差。
