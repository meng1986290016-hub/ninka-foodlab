# 食研工作台 v0.1.0 发布说明草稿

> 状态：未发布草稿。不得直接粘贴到公开 Release；必须先完成下方平台验证并替换全部占位内容。

食研工作台是面向食品研发人员的开源、离线优先桌面应用。`v0.1.0` 建立从原料与供应商版本、配方研发、打样、营养成本试算到正式版本、标签预览、报告和本地备份的第一条完整工作流。

## 主要功能

- 按通用原料维护多供应商、多型号和多规格版本。
- 配方工作台实时估算投料、出成重量、得率、营养、成本和数据完整度。
- 正式版本使用不可变快照，支持替代配方、版本比较、归档和取消归档。
- 按现有配方生成打样配料单，支持打印与 Excel 下载。
- 支持 GB 28050-2011 / 2025 营养标签研发预览和多格式研发报告。
- 支持离线备份预检、原子恢复和失败回滚。
- 食品研发 Agent 可辅助原料资料识别、产品配方提案和标签逆向；保存正式数据仍需人工确认。

## 安装提示

本版本没有使用付费开发者证书：

- macOS 使用 ad-hoc 技术签名，不包含 Apple Developer ID 或公证，首次打开可能被 Gatekeeper 阻止。
- Windows 不做 Authenticode 签名，安装时可能显示“未知发布者”或 SmartScreen 提示。

只从本项目正式 Release 下载，并在安装前核对 SHA-256。完整步骤见[桌面发布与安装说明](../desktop-release.md)。

## 数据与升级

升级前请在“设置 → 数据管理”创建 `.foodrd-backup`，重新选择备份完成预检，再退出旧版本。备份文件未加密、未签名，应保存在受控磁盘或加密存储中。

从旧 schema 恢复时，应用会先在临时副本中迁移和校验；未来版本 schema 会被旧应用拒绝。详见[升级与回退说明](../upgrade-guide.md)和[数据安全说明](../data-safety.md)。

## 重要边界

- 营养、成本、标签和法规输出是研发估算或风险提示，不是检测报告或正式合规结论。
- 未知营养值不会被当作零；缺失价格、密度或营养会降低数据完整度。
- 远程模型只在用户配置并确认发送范围后使用；模型输出和标签逆向结果必须人工复核。
- 当前没有云同步。桌面业务数据默认保存在本机 SQLite。

## 已知限制

- 第一版不提供安装包数字签名和自动更新。
- macOS Intel 与 Windows 的真实安装结果在发布前仍需补齐。
- 实验工艺和感官评价只保留一个研发备注框，不提供固定评分流程。
- 营养声称、特殊膳食、保健食品、婴幼儿食品和特医食品不属于自动正式判定范围。
