# Ninka App Launch Video：项目状态与下一步

## 已确定

- 只制作应用软件、SaaS、AI App 宣传片，不做实物产品广告。
- 目标质感参考 ChatGPT、OpenAI、Linear、Notion、Arc 等软件产品 Launch Video。
- 本次 X 视频只用于镜头语言研究，不复制品牌、UI、文案、音乐或完整动画编排。
- 核心工具为 Codex、Remotion、Remotion Studio。
- Screen Studio 和 Figma 按镜头需要使用；Jitter 只作为可选 UI Motion 素材工具。
- 当前先完成分析和 Storyboard，不直接生成最终视频。
- 新版本应作为独立 Remotion Composition，保留既有横版和竖版成果。

## 当前项目基础（已检查）

- 已有独立 Remotion 工作区：`apps/promo-video/`。
- 已有 8 张由合成演示数据生成的产品界面素材，不读取生产 SQLite、模型密钥或正式业务数据。
- 已有 45 秒竖版和原生 16:9 横版合成；横版为 2560×1440、30 fps、无音频。
- 既有横版采用六场景“左文案、右 UI”为主的版式，技术基础可复用，但节奏更接近功能演示，不是本次参考片的动态 Launch 语言。
- 既有 Composition 已部分使用 Remotion Studio 交互元素，但目前只暴露 CTA、仓库路径、演示标记、音乐文件和音量；大部分文案、时长、镜头位置与动画时间仍为硬编码。
- `public/audio/` 目前没有正式音乐素材。
- 当前工作区已有未提交改动和未跟踪文件；它们均被保留，本次没有提交、推送或覆盖成片。

## 已完成的本轮产物

- 参考视频媒体规格与音轨检查。
- 每 0.5 秒抽帧、8 张 Contact Sheet。
- 逐帧场景变化评分、25 个候选切点三联帧。
- 人工归并后的 15 个主要叙事段落与精确起点抽帧。
- 波形、频谱、响度、瞬态和节拍候选分析。
- 逐镜头语言、排版、UI 动画、转场和声音组织拆解。
- 一版 36 秒 Ninka 原创 Storyboard 草案。

## 仍缺少的素材或决定

### 必须确认

- 最终 CTA 和落地地址。
- 主片时长、是否旁白、首发语言。
- Agent 重点场景选“配方提案”还是“原料资料识别”。
- 成片音乐与音效的合法商用来源；参考片原声不会复用。

### 制作前需要补齐

- 与 Storyboard 对应的最新 UI 状态：供应商版本、配方数值变更、Agent 待复核、人工确认、标签/报告。
- 所有演示数值、按钮名称和状态文案的产品真实性复核。
- 若需要连续鼠标操作，再决定是否用 Screen Studio；可确定性重建的画面优先用 Remotion 截图与组件完成。
- 若某些 UI 需要脱离真实应用重新排版，再使用 Figma；当前不需要为了工具而额外引入 Figma 或 Jitter。

## 下一步执行计划

1. **确认 Storyboard v0.1**：只调整叙事、时长、文案和 CTA，不写视频代码。
2. **建立 shot list 与素材清单**：逐镜头确定截图、重建 UI、录屏和品牌资产来源。
3. **采集/生成演示画面**：使用合成演示数据，保留“演示数据”标识，并核对功能真实性。
4. **设计 Studio 参数模型**：把镜头时长、文案、UI 位置、相机、光标和音频 cue 设为可调参数。
5. **新增参考驱动的独立 Composition**：不覆盖 `NinkaFoodLabPromoLandscape`。
6. **先渲染关键帧和低清无声 animatic**：逐镜头审批；此时仍不做最终成片。
7. **加入授权音乐和音效并混音**：以 scene cue sheet 对齐，不使用参考原声。
8. **最终渲染与验证**：媒体规格、文字可读性、品牌、事实边界、音频峰值和首尾帧均通过后再交付。

当前停在第 1 步：等待 Storyboard 方向确认。
