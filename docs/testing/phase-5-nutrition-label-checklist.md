# 第五阶段：营养标签工作台验收清单

本清单用于验证普通预包装食品的营养标签研发预览。软件结果是规则校验与风险提示，不替代企业最终合规审核。

## 正式配方入口

- [x] 只有配方库中的正式版本显示“生成营养标签”入口。
- [x] 入口传入当前选中的配方 ID 和正式版本 ID。
- [x] 工作台明确显示配方名称和版本号。
- [x] 旧浏览器演示原料缺少过敏原字段时仍可完成配方计算和版本保存。

## 来源复核与计算

- [x] 每个项目同时保留配方估算、检测/人工值、最终来源和完整性。
- [x] 切换到检测结果或人工确认后可以填写数值、来源参考和观测日期。
- [x] 未知值显示为“未知”，不自动改成零。
- [x] 能量由蛋白质、脂肪和碳水化合物重新计算，不接受手工伪造。
- [x] 预览同步显示修约后的标示值和 NRV%。

## 双标准与发布保护

- [x] 2027-03-16 前新建草稿推荐 GB 28050-2011，同时允许选择 GB 28050-2025。
- [x] GB 28050-2011 显示能量、蛋白质、脂肪、碳水化合物和钠。
- [x] GB 28050-2025 增加饱和脂肪和糖，并显示规定提示语。
- [x] 缺少任一强制项目时允许保存草稿，但禁用正式发布并列出原因。
- [x] 数据完整时可以保存草稿并发布不可变正式标签 V1。
- [x] 切换标准不会改写已发布的历史版本。

## 响应式与可用性

- [x] 1573×1000 下来源复核和标签预览并排显示，无横向溢出。
- [x] 809×1000 下顶部操作、设置、来源复核和标签预览改为上下排列。
- [x] 600×1000 下来源宽表改为逐项目卡片，页面无横向溢出。
- [x] 标准选择、来源选择、输入框、保存和发布均可通过语义化控件访问。

## 自动化覆盖

- [x] 工作台加载、人工覆盖、2025 切换和缺项发布保护有组件测试。
- [x] 配方库入口有回调参数测试。
- [x] 浏览器演示、Tauri 命令和可信发布路径有契约测试。
- [x] 旧演示数据缺少过敏原字段有回归测试。
