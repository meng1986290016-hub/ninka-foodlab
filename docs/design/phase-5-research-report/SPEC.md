# 第五阶段研发报告预览设计规格

## 目标

把正式配方版本与正式营养标签版本组合成一份可阅读、可打印、可追溯的食品研发报告。界面延续食研工作台现有白色、深灰与绿色体系，不新增营销式视觉层。

## 信息架构

1. 顶部：返回营养标签、标题、当前配方/标签版本、保存、打印和多格式导出入口。
2. 左侧主区域：灰色画布中的白色研发报告纸张。
3. 右侧信息栏：
   - 报告来源：配方正式版本、营养标签正式版本、规则包修订。
   - 报告记录：未保存或已保存的不可变状态。
   - 包含内容：配方、供应商、营养、成本、目标、过敏原和研发备注。
   - 合规提示。

## 报告文档顺序

1. 标题与生成信息。
2. 目标批量、数据完整度、整批成本、适用标准。
3. 配方组成及供应商。
4. 营养成分与来源。
5. 成本摘要、目标与过敏原、研发备注。
6. 固定版本来源与免责声明。

## 设计系统

- 页面背景：`#ffffff`。
- 预览画布：`#f3f5f4`。
- 主文字：现有 `--color-ink`。
- 次要文字：现有 `--color-ink-soft` 与 `--color-ink-muted`。
- 强调色：现有 `--color-accent`。
- 边框：现有 `--color-border`，报告纸张使用略深的灰色边框。
- 圆角：只用于现有按钮、小状态和来源列表；报告纸张与主要侧栏保持直角。
- 字体：界面使用现有 UI 字体；SVG 使用苹方、微软雅黑、思源黑体与系统无衬线回退。
- 阴影：仅报告纸张使用轻微阴影，表达真实打印页层级。

## 响应式规则

- `> 1180px`：报告纸张与 310px 来源栏并排。
- `901–1180px`：顶部操作换行，主区域仍并排。
- `621–900px`：报告与侧栏纵向排列，侧栏内容使用两列。
- `≤ 620px`：所有操作与侧栏单列，报告按容器宽度完整缩放，不产生横向溢出。

## 交互规则

- 只有正式营养标签版本可以进入报告预览。
- “保存报告记录”保存当前统一文档模型和同源 SVG；成功后按钮变为“报告记录已保存”并禁用。
- 已保存记录不可修改或删除。
- “打印”调用系统打印流程。
- “导出报告”展开 PNG、PDF、XLSX 与 JSON 四种格式；未保存报告会先固定当前记录，再进入导出。
- PNG 与 PDF 从当前同源 SVG 以 2 倍尺寸栅格化；XLSX 与 JSON 从同一不可变文档模型生成。
- 取消系统保存对话框不产生错误提示，也不写入目标文件。

## 可访问性与安全

- 报告 SVG 以带替代文字的 `img` 展示，不使用 `dangerouslySetInnerHTML`。
- 所有按钮有明确可读名称和禁用状态。
- SVG 不加载远程资源，并拒绝脚本、`foreignObject` 和远程 `href/src`。
- XLSX 文本以字符串写入并中和公式前缀；JSON 包含 schemaVersion、规则包和文档快照哈希。
- 原生文件写入先校验格式与快照哈希，再在目标目录原子替换；错误信息不暴露本机路径。
- 错误状态使用 `role="alert"`。
