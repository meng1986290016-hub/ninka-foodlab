# 第二阶段浏览器与响应式验证

日期：2026-07-17

验证地址：`http://127.0.0.1:1420`

## 验证结论

- 1280×720 应用内浏览器：通用原料层级、供应商版本行、更新日期、比较入口与供应商比较抽屉完整显示。
- 620×800 Playwright Chromium：窄屏布局可操作，导航自动收起，比较表保持可读并允许纵向浏览。
- 在 620px 窄屏下创建了“窄屏供应商B”版本，填写 `MD-620`、`32.80 元/kg`、数据来源与研发备注，并保存“蛋白质 = 0”。
- 对比表正确区分“未知”和已确认的 `0 g`，并展示每个供应商版本自己的最新更新日期。
- 浏览器 schema v1 → v2 迁移、分类/供应商/通用原料/版本 CRUD、搜索、复制、编辑、归档和草稿恢复均有自动化测试覆盖。
- 浏览器控制台检查结果：0 errors、0 warnings；只出现 React 开发工具的信息提示。

应用内浏览器截图接口固定输出 1280×720，无法生成计划要求的 620×800 截图，因此窄屏部分按验证规范回退到 Playwright Chromium。两个截图均已用图像查看器人工检查。

## 截图检查项

- 通用原料与供应商版本的两层层级清晰。
- 比较范围限定在同一通用原料内。
- 供应商、型号/规格、价格、完整度、最新更新日期均位于供应商版本行。
- 比较抽屉包含价格、密度、完整度、更新日期、数据来源、研发备注和营养成分。
- 留白、字号、灰绿色中性色、橙色“未知”状态与概念方向一致。
- 620px 下比较表没有挤压成不可读卡片，关闭按钮固定可见。
