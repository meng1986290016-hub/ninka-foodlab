## 桌面人工流程

1. 使用 Tauri 桌面版进入“设置 → 数据管理”。
2. 点击“创建备份”，选择本机目录，确认生成 `.foodrd-backup` 并显示已校验状态。
3. 点击“选择并检查备份”，选择刚才的文件。
4. 核对备份时间、应用版本、数据库版本、记录数、附件数和总大小。
5. 未勾选确认时确认“恢复所选备份”不可点击。
6. 勾选确认并恢复，确认页面提示恢复完成及恢复前安全副本文件名。
7. 无需重启应用，切换到原料库、配方库和标签页，确认恢复数据可以立即读取。
8. 关闭并重新启动应用，再次核对正式配方、双标准标签版本和报告记录。
