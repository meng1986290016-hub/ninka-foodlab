# 第四阶段配方库视觉规范

概念图：

- [配方库与冻结版本详情](./desktop-library.png)
- [配方版本比较](./desktop-version-comparison.png)

## 页面结构

- 沿用现有应用壳：左侧导航、顶部 Agent 入口、数据状态和底部状态栏。
- 主区采用“配方表格 + 冻结版本详情”主从布局，不改成卡片看板。
- 表格负责搜索、筛选和快速定位；右侧检查器负责版本历史、快照内容和操作。
- 详情优先展示版本概览、原料用量、营养、成本、过敏原和研发备注。

## 视觉系统

- 背景保持纯白，表头使用冷浅灰，边框为细灰线。
- 主色沿用克制的绿色，选中行使用浅绿色底和绿色边线。
- 控件圆角 4–6px，正文与表格保持 12–14px 的紧凑研发工具密度。
- 不使用渐变、玻璃效果、重阴影、营销式大标题或装饰性卡片。

## 关键交互

- 支持名称、可选编号和可选标签搜索，以及类型、状态和更新时间筛选。
- 点击配方后默认展示最新正式版本，并可切换历史版本。
- “按当前价格重算”只产生临时对比，不改变正式版本快照。
- “复制为草稿”进入配方工作台继续研发。
- 被其他正式版本引用的配方显示引用数量，并禁止归档。
- 两个以上正式版本可以进入比较状态，基准版本与对比版本始终明确。
- 比较表同时展示两个冻结值和变化值；未知与已经确认的 `0` 必须分开显示。

## 保真核对

| 核对项 | 实现约束 |
| --- | --- |
| 应用壳 | 继续使用现有左侧导航、顶部 Agent、数据状态和底部状态栏，不另建第二套壳。 |
| 主从布局 | 桌面端保持左侧配方表、右侧详情/比较面板；比较时只加宽右侧，不跳到营销式独立页面。 |
| 表格密度 | 保持冷浅灰表头、细分隔线、12–14px 工具型排版和固定的绿色选中行。 |
| 操作层级 | “复制为草稿”为主操作；价格重算、版本比较为次操作；归档保持克制且需要确认。 |
| 差异语义 | 新增/成本下降使用浅绿，移除/成本上升使用浅红橙，其他变化使用中性浅绿灰。 |
| 响应式 | 窄屏和手机宽度改为列表在上、详情或比较在下；宽表只在自身区域横向滚动，不造成页面级溢出。 |
