# 开源版数据安全说明

食研工作台默认本地优先：桌面业务数据保存在用户设备上的 SQLite 和附件目录中，浏览器演示数据保存在当前浏览器的 `localStorage`。项目当前不提供云端同步，也不会自动上传备份。

## 秘密与备份

- API Key 交给操作系统钥匙串保存；数据库只记录不可用于认证的引用。
- `.foodrd-backup` 明确排除钥匙串秘密、缓存、临时文件和未登记附件。
- 备份包有 SHA-256 完整性校验，但**没有加密，也没有数字签名**。任何拿到备份文件的人都可能读取其中的配方、价格、供应商、报告、Agent 会话和来源附件。
- 请把备份保存在受控磁盘或加密存储中，不要直接发送到公共网盘、公开仓库或聊天群。

## 恢复保护

- 恢复先执行只读预检，不兼容、损坏或关联不完整的备份不会覆盖当前数据。
- 恢复前自动创建当前状态安全副本，安装或复核失败时自动回滚。
- UI 和后端均要求明确确认；运行中的 Agent 任务会阻止恢复。
- 恢复成功后重新打开数据连接，避免继续使用恢复前的旧数据库句柄。

## 开源部署建议

- 不要把真实研发数据库、备份、API Key 或供应商资料提交到 Git。
- 发布构建时保持 Tauri capability 最小化；新增 shell、网络或文件系统权限时单独审阅。
- 正式环境升级前先创建并离线验证备份；保留至少一个升级前版本，直到新版本完成验收。
- `.foodrd-backup` 用于灾难恢复，不是脱敏交换格式。需要分享部分资料时应使用单独的原料或报告导出功能。
