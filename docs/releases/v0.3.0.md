# Ninka FoodLab v0.3.0

发布日期：2026-08-30

Ninka FoodLab v0.3.0 继续提供 macOS Apple Silicon、macOS Intel 和 Windows x64 三种安装包。本版重点完善本机数据安全操作、版本信息与手动更新检查，并提高 Ninka Agent 将工具结果映射到待复核成果时的准确性。

## 下载与安装

- macOS 13.5+ Apple Silicon（M1 及更新芯片）：[`food-rd-studio-0.3.0-macos-arm64.dmg`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.3.0/food-rd-studio-0.3.0-macos-arm64.dmg)
- macOS 13.5+ Intel：[`food-rd-studio-0.3.0-macos-x64.dmg`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.3.0/food-rd-studio-0.3.0-macos-x64.dmg)
- Windows 10/11 x64：[`food-rd-studio-0.3.0-windows-x64-setup.exe`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.3.0/food-rd-studio-0.3.0-windows-x64-setup.exe)

发布版已内置 Agent 运行组件，普通用户不需要另外安装 Node.js 或 pnpm。当前 macOS 安装包未使用 Apple Developer ID 签名且未公证，Windows 安装包未使用 Authenticode 签名，系统可能显示开发者或 SmartScreen 提示。请只从本发布页下载，并在继续安装前核对 [`SHA256SUMS.txt`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.3.0/SHA256SUMS.txt)。

## 本次更新

### 本机数据安全

- 新增“清空本机研发数据”流程，执行前会统计受影响的原料、配方、标签、报告、导入草稿、Agent 会话和附件。
- 默认先创建并校验清空前安全快照；快照失败时不会继续清空。
- 支持从设置页恢复最近一次清空前快照，恢复与失败回滚继续使用现有备份安全机制。
- 清空研发数据不会删除模型配置、系统钥匙串中的 API Key、内置资料和用户之前主动导出的备份文件。

### 版本与更新

- 设置页新增“关于 Ninka FoodLab”，直接显示当前安装包版本。
- 可以手动检查 GitHub 上的最新稳定版，只有用户点击“检查更新”时才访问 GitHub，应用启动时不会自动联网。
- 发现新版时只打开本项目的 GitHub Release 页，不会自动下载或安装。

### Ninka Agent

- 改善 Agent 工具结果与实际原料导入草稿、配方提案之间的关联，避免把任务或附件编号误当成待复核成果。
- 需要本地审计的操作，只有真正完成后才会投影为已完成成果；失败或未确认的操作不再被误判为成功。
- 改善会话事件的脱敏、来源保留与待复核状态展示。

## 升级与数据边界

从 v0.2.1 覆盖安装前，建议先在“设置 → 数据管理”中创建一份 `.foodrd-backup`并完成预检。本版沿用数据库 Schema 22 和备份格式 1，没有新增数据库迁移。营养、成本和法规结果属于研发估算与风险提示，不替代实验检测、正式成本核算或标签合规审核。

更完整的安装、未签名提示、数据安全与问题反馈方法见 Release 附带的 `README.md`。
