## 桌面设置页

参考现有食研工作台设置页的白色 / 冷浅灰 / 绿色视觉系统，设计“设置 → 数据管理”。页面只包含两个按顺序排列的工作区：

1. 创建离线备份，说明包含 SQLite 和已登记附件，排除 API Key、缓存和临时文件。
2. 检查并恢复 `.foodrd-backup`，展示已选文件名、备份时间、应用版本、schema 迁移、数据记录数、附件数和总大小。

恢复区域必须有浅黄色安全说明、不可跳过的确认复选框和低强度危险色恢复按钮。保持桌面工具的紧凑密度，不使用营销卡、图表、渐变、插画、云同步或定时备份控件。
