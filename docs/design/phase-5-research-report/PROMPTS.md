# 研发报告预览概念图提示词记录

## 主概念图

为中文食品研发桌面应用“食研工作台”设计一张完整桌面界面概念图，尺寸约 1572×1000。沿用现有白色背景、浅灰边框、深灰文字和克制绿色强调色。左侧是原料库、配方工作台、配方库、设置导航；顶部保留“食品研发 Agent”、本地数据库和离线可用状态。

主内容是“研发报告预览”：顶部显示返回营养标签、配方与标签版本，以及“保存报告记录”“打印”“导出报告（下一步支持）”。左侧大区域是一张清晰的白色 A4 风格食品研发报告，包含标题、生成日期、配方版本、目标批量、数据完整度、整批成本、适用标准、配方组成及供应商、营养成分及来源、成本摘要、目标与过敏原、研发备注和固定来源。右侧是报告来源、报告记录状态、包含内容和合规提示。

界面应像成熟桌面研发工具：信息密度适中、表格清晰、报告纸张有轻微阴影；不使用卡片网格、营销标题、渐变、装饰性徽章或虚构导航。所有应用控件与界面文字应可由 React/CSS 实现。
