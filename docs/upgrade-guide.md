# 升级与回退说明

## 升级前

1. 在旧版本“设置 → 数据管理”中创建 `.foodrd-backup`。
2. 重新选择该文件完成预检，确认清单、校验和和数据库完整性通过。
3. 退出应用并保留备份，不要用新版本覆盖唯一副本。

## 升级时

- 应用启动时按顺序执行 SQLite schema 迁移。
- 新版本可以恢复当前声明支持范围内的历史 schema，并在临时副本上先完成迁移和校验。
- 比当前应用更新的未来 schema 会被拒绝，避免旧版静默降级数据库。
- 已发布的配方、营养标签和研发报告保持不可变；规则包更新不会自动改写历史标签。

## 升级后

1. 打开原料库、配方库、营养标签和研发报告，抽查一条正式记录。
2. 在“数据管理”中创建一次新版本备份并完成预检。
3. 完成业务验收前保留升级前备份。

## 需要回退时

优先使用仍支持该备份 schema 的应用版本，在“数据管理”中恢复升级前备份。不要手工复制运行中的 SQLite 主文件，也不要单独替换数据库而遗漏附件。若界面提示备份版本不受支持，应停止操作并使用兼容版本，不要修改清单版本号绕过检查。
