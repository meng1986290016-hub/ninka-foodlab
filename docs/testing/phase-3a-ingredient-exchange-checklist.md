# 第三阶段 3A：原料资料交换人工验收清单

本清单用于验收“无大模型也能独立使用”的原料资料导入、人工复核、保存和导出闭环。

## 测试环境说明

- 浏览器演示模式可验证菜单、抽屉、逐条复核、忽略和确认保存等界面流程，但不会真实读取文件内容，也不会在本机生成 CSV/XLSX 文件。
- Tauri 桌面模式用于验证真实文件解析、附件留存、CSV/XLSX 生成、重启恢复和孤立附件清理。
- 全程不配置模型、API Key、CLI 或 MCP；3A 的所有项目仍应可用。

## 1. 模板与基础导入

- [ ] 在原料库点击“数据交换”，确认有“导入原料资料”“下载 CSV 模板”“下载 XLSX 模板”“导出原料库”四个入口。
- [ ] 分别下载 CSV 与 XLSX 模板，确认文件可以被常用表格软件打开，中文列名完整且示例行存在。
- [ ] XLSX 模板的“价格单位”和“营养基准”可以通过下拉选择。
- [ ] 按模板填写两行同名“脱脂乳粉”，供应商分别为“供应商A”和“供应商B”，导入后应生成两张独立复核卡片。
- [ ] 两条记录保存后应归入同一个“脱脂乳粉”通用原料，展开后显示两家供应商版本，而不是两个同名通用原料。

## 2. 人工复核字段

- [ ] 将分类改为一个尚不存在的名称，确认正式保存时自动建立自定义分类。
- [ ] 在支持自定义营养成分的草稿中加入一个未建档项目（例如“乳糖（g）”），确认保存前提示将新建该营养成分定义，保存后可在供应商版本中查看。
- [ ] 分别填写“所含过敏原”和“可能含有的过敏原”，保存后两种关系应保持分离。
- [ ] 将某营养值留空、另一个明确填写 `0`；保存后前者仍为未知，后者显示为 0。
- [ ] 分别导入“每100g”和“每100mL”记录，确认营养基准不被互相替换；使用每100mL且涉及质量换算时应保留密度。
- [ ] 原始附件区域只显示文件名、类型和大小，不显示本机绝对路径或文件哈希。
- [ ] 研发备注、数据来源、供应商和型号/规格经人工修改后，正式保存值与复核值一致。

## 3. 错误、重复与取消

- [ ] 导入损坏的 CSV/XLSX 或伪装扩展名文件，界面显示结构化错误，不创建正式原料。
- [ ] 在数字单元格填入带单位文本（例如 `12mg`），确认显示来源文件、行号、列名和修正提示，并禁用“确认导入全部”。
- [ ] 导入与现有“供应商 + 型号/规格”重复的记录，未勾选重复确认时不得保存；勾选后才允许继续。
- [ ] 在多条预览中点击“忽略这一条”，确认其不会随“确认导入全部”保存。
- [ ] 取消导入任务后不应出现半保存的分类、供应商、通用原料或供应商版本。

## 4. 恢复、导出与回环

- [ ] 生成复核草稿后关闭应用并重新打开，任务、草稿、人工修改和来源附件仍然存在。
- [ ] 对已取消且所有草稿均已忽略的任务执行附件清理，只删除已放弃的来源文件；正式供应商版本引用的附件必须保留。
- [ ] 将原料库分别导出为 CSV 和 XLSX，再导入到一个空数据库；通用原料、供应商版本、价格、营养基准、营养值、过敏原、来源和备注应保持一致。
- [ ] 导出以 `=`, `+`, `-`, `@` 开头的文本，使用表格软件打开时不得被当作公式执行。
- [ ] 完成以上流程时，设置中无需存在任何大模型配置；离线状态不影响模板、导入复核、正式保存和导出。
