# 食研工作台路线图

## 已完成

- 第一至三阶段：供应商维度原料库、资料导入、LLM/API/CLI 配置与食品研发 Agent 草稿复核。
- 第四阶段：配方工作台、正式版本、半成品引用、成本营养估算、配方库与版本比较。
- 第五阶段：GB 28050-2011 / 2025 双标准营养标签、不可变发布快照、研发报告、SVG/PNG/PDF/XLSX/JSON 输出、离线备份与原子恢复。

## 后续候选

- 在现有 Agent Chat 中增强原料资料识别质量、来源引用和批量复核效率。
- 扩充实验工艺与感官评价时仍保持用户已确定的单一备注框，不预设固定行业流程。
- 评估配料表、过敏原提示和其他包装信息的辅助生成；法规结果继续定位为风险提示和人工复核支持。
- 根据社区反馈评估可选的加密备份、选择性数据交换和跨设备方案，不改变默认本地优先。
- 补充正式安装包、发布自动化和各平台安装说明；是否进行代码签名由发布渠道与维护者决定。

路线图不承诺发布日期。新功能优先保证数据可追溯、历史版本不可变、离线可用和人工确认边界。
