# 食品研发工具实施路线图

## 拆分原则

设计说明覆盖多个可独立验收的子系统。每个阶段都必须交付可运行、可测试的成果；下一阶段只依赖前一阶段公开且已测试的接口。

## 阶段顺序

1. 确定性计算引擎
   - 建立 TypeScript 工作区、十进制定点边界、单位换算、营养、成本、目标、配方补足和多层半成品展开。
   - 交付无界面的 @food-rd/core 包及端到端配方计算测试。

2. Tauri 桌面外壳与本地数据
   - 建立 React + Tauri 2 桌面应用、SQLite 迁移、仓储接口、安全事务、草稿恢复和本地设置。
   - 交付可在 Windows/macOS 启动的空壳应用，以及原料增删改查和数据库恢复测试。

3. 原料库与数据交换
   - 实现原料、营养定义、价格、密度、过敏原、来源、Excel/CSV 导入导出和数据完整度界面。
   - 交付从模板导入原料并在应用内维护的完整流程。

4. 配方工作台与配方库
   - 实现普通原料/半成品、锁定与补足、批量缩放、实时营养成本、目标、版本快照、备注、搜索和版本比较。
   - 交付从原料选择到正式版本保存、复制和比较的核心研发闭环。

5. 中国营养标签、报告与备份
   - 实现 GB 28050-2011/2025 规则包、金样测试、PDF/Excel/SVG/PNG/JSON 输出、备份恢复和数据库升级保护。
   - 交付可审计的双标准标签预览与全部输出格式。

6. 食品研发 Copilot 与 MCP
   - 实现模型供应商适配、系统安全凭据、受控工具、草稿生成、审批、审计轨迹、隐私提示和 MCP 扩展点。
   - 交付可选启用、无 API Key 时不影响核心功能的工作台 Copilot。

7. 未签名开源发布
   - 完成 Apache-2.0、贡献指南、GitHub Actions 双平台构建、SHA-256、安装警告、可复现构建说明和升级文档。
   - 交付 Windows/macOS 未签名安装包及完整源码发布流程。
