# Ninka FoodLab v0.2.0

Ninka FoodLab v0.2.0 现已正式发布，提供 macOS Apple Silicon、macOS Intel 和 Windows x64 三种安装包。本版重点完善了 Ninka Agent 的会话体验、模型接入、归档管理、主题与设置界面，并将 Agent 运行组件完整内置到桌面应用中。

## 下载与安装

- macOS 13.5+ Apple Silicon（M1 及更新芯片）：[`food-rd-studio-0.2.0-macos-arm64.dmg`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.2.0/food-rd-studio-0.2.0-macos-arm64.dmg)
- macOS 13.5+ Intel：[`food-rd-studio-0.2.0-macos-x64.dmg`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.2.0/food-rd-studio-0.2.0-macos-x64.dmg)
- Windows 10/11 x64：[`food-rd-studio-0.2.0-windows-x64-setup.exe`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.2.0/food-rd-studio-0.2.0-windows-x64-setup.exe)

macOS 用户下载对应芯片的 DMG 后，将 `Ninka FoodLab.app` 拖入“应用程序”文件夹。Windows 用户双击 `-setup.exe` 并按安装向导操作即可。发布版已经内置运行组件，不需要另外安装 Node.js 或 pnpm。

当前 macOS 安装包未使用 Apple Developer ID 签名且未公证，Windows 安装包未使用 Authenticode 签名，因此系统可能显示开发者或 SmartScreen 提示。请只从本发布页下载，并在选择“仍要打开”或“仍要运行”前核对 [`SHA256SUMS.txt`](https://github.com/meng1986290016-hub/ninka-foodlab/releases/download/v0.2.0/SHA256SUMS.txt)。

## 本次更新

### Ninka Agent

- 将原有任务面板改造成更自然的会话式界面，减少无意义的完成条件和步骤占位。
- 支持会话归档、已归档会话查看与恢复，并修复失联运行状态导致无法归档的问题。
- 稳定输入区、运行状态与会话列表布局，长附件名称不再挤掉移除按钮。
- 在同一会话中直接切换 API 模型，历史消息和成果保持连续。
- 保留受控的配方上下文、工具审批、结构化成果和本地会话记录。

### 模型与运行组件

- 内置固定版本的 Agent 运行组件，安装后无需另行配置 Node.js 或 pnpm。
- 改进 DeepSeek、Kimi 和 OpenAI 兼容 Provider 的设置、凭据保存与错误提示。
- 模型设置重新分组，停用 ChatGPT 订阅登录入口，继续支持用户自行配置 API Provider。
- 启动前校验内置运行组件的架构和关键文件，组件损坏时停止任务并给出明确提示。

### 界面与平台

- 支持跟随系统、浅色和深色三种主题，并改善文字、图标、按钮及表单的对比度。
- 优化 Agent 侧栏、独立窗口、通用设置和 LLM 设置在不同窗口宽度下的布局。
- 提供 macOS Apple Silicon、macOS Intel 和 Windows x64 独立安装包及运行时完整性校验。

## 数据与使用边界

升级或覆盖安装前，建议先在应用的数据管理页创建一份 `.foodrd-backup` 备份；详细注意事项见[升级说明](https://github.com/meng1986290016-hub/ninka-foodlab/blob/main/docs/upgrade-guide.md)。营养、成本和法规结果属于研发估算与风险提示，不替代实验检测、正式成本核算或标签合规审核。
