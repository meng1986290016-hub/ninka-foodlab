# 食研工作台路线图

## 已完成

- 第一至三阶段：供应商维度原料库、资料导入、LLM/API/CLI 配置与食品研发 Agent 草稿复核。
- Agent 原料复核增强：多原料连续复核、字段级来源追溯，以及高/中/低可信度与优先复核提示。
- 第四阶段：配方工作台、正式版本、半成品引用、成本营养估算、配方库与版本比较。
- 第五阶段：GB 28050-2011 / 2025 双标准营养标签、不可变发布快照、研发报告、SVG/PNG/PDF/XLSX/JSON 输出、离线备份与原子恢复。

## 当前开发路径

1. **当前版本收口**：完成核心流程回归、错误提示和浏览器/桌面双模式验证。本轮已完成。
2. **品牌基础接入**：在应用侧栏、折叠导航和桌面图标中统一使用 Ninka FoodLab 的“聚合种子”标志，并沉淀四色品牌令牌。本轮已完成。
3. **界面规范化**：以现有品牌规范优化字体层级、色彩、间距、按钮、表格、空状态和 Agent 提案卡，不改变营养、成本与版本计算内核。本轮已完成。
4. **桌面发布包装（进行中）**：已完成 macOS Apple Silicon 的 `.app`、ad-hoc 签名、DMG、校验和与隔离启动验证，并配置 macOS Intel / Windows x64 手动构建；Windows 与 Intel Mac 的真实构建和试装仍待验证。
5. **开源呈现（进行中）**：已建立中文仓库首页、Apache-2.0、贡献与安全说明、品牌截图、平台依赖清单和 `v0.1.0` 发布草稿；远端仓库配置、跨平台 Artifact、私密漏洞报告入口和正式 Release 仍待完成。

## 后续候选

- 在现有 Agent Chat 中继续增强复杂表格、模糊图片和多来源资料的识别质量。
- 扩充实验工艺与感官评价时仍保持用户已确定的单一备注框，不预设固定行业流程。
- 评估配料表、过敏原提示和其他包装信息的辅助生成；法规结果继续定位为风险提示和人工复核支持。
- 根据社区反馈评估可选的加密备份、选择性数据交换和跨设备方案，不改变默认本地优先。
- 补充发布自动化；第一版按已确认方案提供未签名安装包，并在安装说明中解释系统安全提示。

路线图不承诺发布日期。新功能优先保证数据可追溯、历史版本不可变、离线可用和人工确认边界。

## 当前版本收口验收（2026-08-08）

- 核心计算：17 个测试文件、60 条用例通过。
- 桌面前端：50 个测试文件、195 条用例通过；复杂交互用例使用独立超时，避免全量回归时模拟输入相互污染。
- 原生端：`cargo fmt --check`、`cargo clippy --all-targets -- -D warnings` 和 162 条 Rust 测试通过，包含中国模型服务、CLI、MCP、备份恢复与仓储接口。
- 工程校验：全仓 TypeScript 类型检查、生产构建和 Ninka FoodLab 品牌资源完整性校验通过；构建仅保留现有的大分块提示，不影响产物生成。
- 浏览器演示模式：人工验证原料左右分栏、通用原料搜索、多供应商/型号计数、配方库与工作台往返、新建配方入口、研发中/归档页签、LLM 服务商列表及 Agent 面板。
- 桌面模式边界：原生命令、数据库迁移、文件导出与 Provider 适配已由 Rust 和前端契约测试覆盖；安装包与真实系统安装体验留到“桌面发布包装”阶段验证。

## 界面规范化验收（2026-08-08）

- 品牌与令牌：在既有 Ninka FoodLab 色彩体系内补齐统一的页面边距、卡片表面、细边框、阴影、紧凑控件高度和小字号令牌，没有引入第二套视觉语言。
- 原料库：保留已确认的左右分栏结构，统一搜索、列表选中态、具体原料表头和卡片边界。
- 配方库：筛选区改为稳定网格，常规桌面宽度保持单行；Agent 打开时使用两列筛选并隐藏低优先级的“最近更新、引用”列，保留产品、状态、类型、版本、投料和成本。金额展示统一为两位小数，内部精度不变。
- 配方工作台：统一页头、批次摘要、配方表格、成本附加项、研发备注和实时结果的层级、圆角与边界。
- 设置与 Agent：通用设置改为内容卡，模型服务卡片收紧纵向节奏；Agent 消息、草稿卡、提案卡、操作按钮和输入区采用一致的表面与点击面积。
- 视觉证据：在同一视口和相同数据状态下完成六组改前/改后对照，并额外验证 Agent 打开时的受限宽度布局；详见 `docs/design/ui-normalization.md`。
- 回归验证：核心层 17 个文件、60 条用例通过；桌面前端按模块分组覆盖全部 50 个文件、195 条用例通过；全仓类型检查、生产构建和品牌资源完整性校验通过。Vitest 单进程全量模式在本机出现过工作进程启动超时，因此最终验收采用相同文件集合的分组运行，避免把测试框架的时钟/进程波动误判为产品回归。

## 桌面发布包装进展（2026-08-08）

- macOS arm64：发布模式成功生成并 ad-hoc 签名 `食研工作台.app`；应用、内置 MCP 可执行文件和镜像内应用均通过严格签名校验。
- DMG：使用不依赖 Finder 的确定性脚本生成 `food-rd-studio-0.1.0-macos-arm64.dmg`；镜像校验、SHA-256、只读挂载和 `/Applications` 入口均通过。
- 隔离启动：在临时 HOME 中首次启动并重启应用，本地数据库完整、11 个迁移保持一致，未触碰正式用户数据。
- GitHub 构建：已配置 macOS Apple Silicon、macOS Intel 和 Windows x64 的人工工作流，并补齐干净运行器上的 Python 品牌校验依赖。
- 待完成：首次运行 GitHub 工作流，验证 macOS Intel 与 Windows NSIS 真实产物，并在对应系统完成安装/卸载冒烟测试。详细证据见 `docs/testing/desktop-release-checklist.md`。
