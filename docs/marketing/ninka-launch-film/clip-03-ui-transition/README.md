## Clip 03: 从 Logo 进入真实原料库

### References

- Characters: none。
- Location and props: 首帧为完整 Ninka 九模块图形；尾帧为深森林绿竖屏舞台上的真实 Ninka FoodLab 原料库窗口。
- Style: 高端软件发布片，真实 UI 证据优先，Forest 背景与 Grain 暖金光作为品牌连续性。

### Start state

9:16 竖屏。完整 Ninka 九模块图形位于画面中央，中央 Grain 黄色圆形微微发光，背景为深森林绿色空间与少量安静微尘。摄影机固定在中心轴线。

Opening anchors: vertical frame; centered nine-module mark; warm central Grain circle; fixed camera axis; dark Forest background.

### Camera and action

- `12.0–12.7 秒`：Logo 保持稳定，中央黄色圆形完成一次轻微呼吸增亮；摄影机不移动。
- `12.7–13.7 秒`：中央黄色圆形向外扩展成一块横向暖色光面；其余八个模块沿短弧向外退开，化为少量暖金和奶油白颗粒，不能爆炸或高速旋转。
- `13.7–14.8 秒`：横向光面继续扩展为带圆角的软件窗口轮廓，大小与尾帧一致。窗口内部保持柔和失焦，只出现明暗层次，不生成新的按钮、文字或图标；摄影机仍保持正面中心视角。
- `14.8–15.3 秒`：窗口内部由模糊平滑地变清晰，真实原料库界面按照尾帧完整显现；外围颗粒被吸收到窗口边缘，形成很细的暖金边缘光。
- `15.3–16.0 秒`：所有运动停止，窗口位置、大小、圆角、真实 UI 内容、背景光线和留白准确落到尾帧，保持 0.7 秒静止，方便接入录屏。

### Dialogue and sound

无对白、无旁白、无字幕。生成画面按静音处理；低频脉冲、颗粒移动和窗口落位音效在剪映后期添加。

### End state

真实原料库截图以横向圆角软件窗口形式正面悬浮于深森林绿 9:16 舞台中央，窗口左上角品牌、原料列表与主数据区保持真实且完整。窗口宽 980 px、高 592 px，左上角位于画布 `(50, 664)`；摄影机停止，背景和窗口均无继续运动。

Closing anchors: exact supplied UI frame; front-facing flat window; centered vertical stage; stable final hold; no regenerated interface content.

### Constraints

真实 UI 的文字、按钮、数字、图标和布局必须以尾帧为准；不增加、删除、替换或重写任何界面内容。不要把窗口变成手机、平板或实体显示器；不要出现人物、键盘、桌面、实验室、蓝紫霓虹、HUD、额外 Logo、字幕或水印。无跳切、甩镜、快速旋转、强闪白、爆炸、界面弯曲和文字闪烁。

## 剪映衔接参数

16 秒以后使用 `xhs-ui-stage-forest-v01.png` 作为 9:16 背景，将 Mac 横屏录屏放在：

- 左上角：`X = 50 px`、`Y = 664 px`
- 显示尺寸：`980 × 592 px`
- 画面比例：保持原录屏 `16:9`，不要拉伸

录屏开头先静止约 0.3–0.5 秒，并保持与尾帧相同的原料库状态；随后再开始鼠标移动和局部放大。这样 Seedance 尾帧切到真实录屏时不会跳动。
