# 第五阶段研发报告验证清单

## 自动化

- [x] 统一报告模型包含配方、供应商、营养、成本、目标、过敏原、备注和规则来源。
- [x] 相同输入生成确定性 SVG 金样。
- [x] SVG 使用本地字体回退、转义用户文本且不加载远程资源。
- [x] 浏览器存储从 v6 升级到 v7，并保留不可变报告记录。
- [x] SQLite migration 7 创建表、索引、来源校验和不可变触发器。
- [x] 报告记录关闭后重新打开仍保持原始 JSON 与 SVG。
- [x] 0 与未知值保持区分。
- [x] 错误来源关联、重复 ID 和活动 SVG 内容被拒绝。
- [x] JSON 可回读 schemaVersion、规则包、快照哈希和完整文档。
- [x] XLSX 可回读七个工作表，用户文本的公式前缀被中和。
- [x] PNG 与 PDF 可由标准解析器打开，四种格式共享同一文档哈希。
- [x] 原生导出失败时保留已有目标文件并清理临时文件。
